# House_Prices_Prediction

A Machine Learning Regression project that predicts house prices using the King County House Sales dataset. Includes data preprocessing, exploratory data analysis, feature engineering, model comparison, Random Forest hyperparameter tuning, and model evaluation.

## 1. Project Overview

The goal of this project is to develop a Machine Learning model
that predicts house prices based on different property features.

## 2. Dataset Information

- Dataset: King County House Sales
- Target Variable: Price
- Problem Type: Supervised Learning
- Learning Task: Regression

## 3. Project Objectives

- Understand and analyze the dataset.
- Perform data cleaning and preprocessing.
- Explore relationships between features.
- Apply feature engineering techniques.
- Train multiple regression models.
- Compare model performance.
- Tune Random Forest hyperparameters.

## 4. Technologies & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 5. Project Workflow

1. Import required libraries.

5. Perform feature engineering.
6. Split data into training and testing sets.
7. Train regression models.
8. Compare model performance.
9. Perform Random Forest hyperparameter tuning.

## 6. Models Implemented

- Random Forest Regressor

## 7. Model Evaluation

The models are evaluated using:
